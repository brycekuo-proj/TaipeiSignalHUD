# 00 — Project Scope

## Working name

TaipeiSignalHUD

## Problem

台灣一般導航目前沒有穩定提供「前方號誌剩餘秒數」的主流功能。使用者希望在行車中直接看到當前道路前方數個路口的號誌剩餘時間，並同時保留目前時速、測速照相與科技執法資訊。

## Product definition

本產品不是導航 App，而是 **Driving Information HUD / 號誌資訊儀表**。

核心輸出只有資訊：

- GPS 當前時速
- 當前道路 / 當前行進方向
- 前方三個適用路口的：路口名稱、距離、目前預測燈態、剩餘秒數 / 區間
- 固定測速 / 區間測速資訊
- 科技執法資訊
- 資料可信度 / 同步狀態（可低調呈現）

## Explicit non-goals

MVP 不做：

- 地址搜尋
- Turn-by-turn navigation
- POI
- 路線規劃
- 語音導航
- 駕駛操作建議
- 「可以通過 / 建議加速 / 建議減速 / 踩煞車」等決策輸出
- 全台覆蓋
- 對所有路口保證精確倒數

## Safety/product responsibility principle

軟體只呈現「預估資訊」，不替使用者做駕駛判斷。

必須固定遵守：

1. 現場號誌優先。
2. 預測不可靠時顯示 `--`。
3. 不把估計值偽裝成官方即時秒數。
4. 不提供會誘導駕駛加速趕燈或突然煞車的訊息。

## Data strategy

優先級：

1. 官方 SPaT / V2X（若未來合法可用）
2. 官方號誌時制 + 已同步 phase/offset
3. 官方號誌時制 + GPS/歷史觀測校正
4. 歷史號誌模型 / 相鄰協調號誌模型
5. 資料不足：不顯示秒數

交通壅塞、VD 等資料只做資料清洗與異常偵測，不直接當成號誌真值。
